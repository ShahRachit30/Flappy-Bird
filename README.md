# Flappy Bird

A Java-based implementation of the classic Flappy Bird arcade game.

## About the Project

Flappy Bird is a simple arcade-style game in which the player controls a bird and navigates through gaps between obstacles without colliding with them.

This project recreates the classic gameplay experience using Java while exploring fundamental programming concepts and game development logic.

## Features

- Bird movement and controls.
- Obstacle generation.
- Collision detection.
- Score tracking.
- Classic Flappy Bird-style gameplay.

## Technologies Used

- Java
- Java Swing / AWT (if used in the project)
- IntelliJ IDEA

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- IntelliJ IDEA or any Java-compatible IDE

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ShahRachit30/Flappy-Bird.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Flappy-Bird
   ```

3. Open the project in IntelliJ IDEA.

4. Locate the main Java class containing the `main()` method.

5. Run the application.

## How to Play

- Control the bird using the game's designated input.
- Navigate through the gaps between obstacles.
- Avoid collisions.
- Try to achieve the highest score possible.

## Learning Outcomes

- Understanding Java programming fundamentals.
- Applying Object-Oriented Programming concepts.
- Working with game loops and event handling.
- Implementing collision detection.
- Developing basic game logic.
